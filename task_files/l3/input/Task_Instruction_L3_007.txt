All steps must be followed strictly according to the **TASK FLOW** to ensure a unique, reproducible result.

- ChemDraw (current active window) and Excel are already open. You don't need to start new instances. Complete Phase 1 in ChemDraw. When Phase 2 begins, switch to the existing Excel window (via Alt+Tab or the taskbar) and continue there.
- All results must be saved to the specified absolute paths on the local machine.
