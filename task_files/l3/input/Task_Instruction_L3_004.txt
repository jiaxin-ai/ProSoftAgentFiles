PHASE 1 — ImageJ (RGB Channel Split and Export)

Goal: Split "ImageJ_L3.jpg" into R/G/B channels in ImageJ and save each channel as a separate JPEG to the specified paths.

Steps:
1.1 In ImageJ, go to "Image > Color > Split Channels" to split the image "ImageJ_L3.jpg" into R/G/B channels.
1.2 Use "File > Save As > Jpeg..." to save each channel image as JPEG files at the following locations:
    - Save the Red channel image as JPEG at "C:/Users/Docker/Downloads/Red.jpg".
    - Save the Green channel image as JPEG at "C:/Users/Docker/Downloads/Green.jpg".
    - Save the Blue channel image as JPEG at "C:/Users/Docker/Downloads/Blue.jpg".

Phase 1 completion condition: Three channel image files are saved successfully at the specified locations.

PHASE 2 — Photoshop (Concatenate Images into a Panel)
