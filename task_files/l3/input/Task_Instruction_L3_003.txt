All steps must be followed strictly according to the **TASK FLOW**, ensuring consistency in file paths, formats, and requirements.

––––––––––––––––––––––––––––––––––––––––
**TASK FLOW:**
––––––––––––––––––––––––––––––––––––––––
PHASE 1 — ImageJ (Angle Measurement)

Goal: Measure four vein angles (top→bottom order) in Leaf.tif using ImageJ, and export the data to C:/Users/Docker/Downloads/Results.csv.

Steps:
1.1 In ImageJ, navigate to "Analyze > Clear Results" to ensure the Results table is empty.
1.2 Use the "Angle Tool" to draw (from top to bottom) the four vein angles.
    For each angle:
        go to "Analyze > Measure", a new row with an "Angle" value will appearin the ImageJ "Results" window.
    After all four measurements, confirm the "Results" window contains 4 rows of data.
1.3 In the "Results" window, go to "File > Save As… > Results…" and save the data to the exact path: "C:/Users/Docker/Downloads/Results.csv"
    The file should contain exactly 4 rows of data with an "Angle" column.

Phase 1 completion condition:
The file "C:/Users/Docker/Downloads/Results.csv" is successfully created with the correct column names and 4 rows of data.

––––––––––––––––––––––––––––––––––––––––
PHASE 2 — Excel (Data Cleaning and Analyzing)

Goal: Import the angle measurements from ImageJ into Excel, keep only the Angle column (as Column A), compute radians/normalization/rounded values, and save the processed workbook to "C:/Users/Docker/Downloads/Processed_Results.xlsx".

Steps:
2.1 Open Excel and create a blank workbook. Go to "Data > From Text/CSV", and import the file from "C:/Users/Docker/Downloads/Results.csv".
2.2 Keep only the "Angle" column. Delete any extra columns. Ensure A1 = "Angle", and the four angle values are in A2:A5.
2.3 Add helper column headers in row 1:
    - In B1, enter "Angle_rad".
    - In C1, enter "Norm_Angle".
    - In D1, enter "Rounded".
2.4 Enter formulas for row 2 and fill down to row 5:
    - In B2, enter: "=RADIANS(A2)"
    - In C2, enter: "=A2/AVERAGE($A$2:$A$5)"
    - In D2, enter: "=ROUND(C2,3)"
    Then drag B2:D2 down to row 5 so that B2:D5 are filled.
2.5 Add a summary row (row 6):
    - In A6, enter "AVG".
    - In B6, enter: "=AVERAGE(B2:B5)"      (average radians)
    - In C6, enter: "=AVERAGE(C2:C5)"      (average normalized angle)
    - In D6, enter: "=AVERAGE(D2:D5)"      (average rounded normalized angle)
2.6 Save the final workbook to the exact path: "C:/Users/Docker/Downloads/Processed_Results.xlsx"

Phase 2 completion condition:
The file "C:/Users/Docker/Downloads/Processed_Results.xlsx" is created successfully with the required columns (Angle, Angle_rad, Norm_Angle, Rounded), rows (AVG) and values.
