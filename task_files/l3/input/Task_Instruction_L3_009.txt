PHASE 3 — RGui (Compute DBE and Delta_Mass)

Goal: In RGui, write and execute an R script that reads the Phase 2 CSV, parses C and H counts from "Chemical Formula", computes DBE and Delta_Mass, and writes an output CSV with a fixed schema and ordering. Do not hardcode numeric results; compute them from input.

Steps: In RGui, write and execute an R script that performs these actions in order:
3.1 Read data from: "C:/Users/Docker/Downloads/Properties.csv"
    - Treat the first row as headers.
    - Read numeric columns as numbers.

3.2 Parse C and H element counts from "Chemical Formula":
    - The value is exactly of the form "C<number>H<number>" (e.g., "C6H6", no space).
    - Extract:
        C_count = integer after "C"
        H_count = integer after "H"

3.3 Compute derived descriptors for each row using the columns from 3.1 and the counts from 3.2:

                   Output as an integer (no decimal places).
    - Delta_Mass = ("Molecular Weight") - ("Exact Mass")
                   Round to 4 decimal places.

3.4 Build a data frame with columns in this exact order and names:
    Molecule, Chemical Formula, C_count, H_count, DBE, Delta_Mass

3.5 Write the resulting table to: "C:/Users/Docker/Downloads/Results.csv"

    - No quotes around data values.
    - Encoding: UTF-8.
